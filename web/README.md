# Frontend for YYB

This is the Vue 3 frontend for the YYB project.

## Project Setup

```sh
npm install
```

## Compile and Hot-Reload for Development

```sh
npm run dev
```

## Type-Check, Compile and Minify for Production

```sh
npm run build
```

## Configuration

The project is configured to proxy API requests to `http://localhost:8000`.
If your backend is running on a different port, update `vite.config.ts`.
